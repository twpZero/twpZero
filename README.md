### Hi, I'm Remi 👋

Senior cyber security instructor, former CERT member, security firefighter.
I build small tools for SOC, CERT and DFIR teams, and I teach with them on [bit-bang.org](https://bit-bang.org/).

> **Your estate is stable. The attacker's cheap layers churn. Baseline the stable part, and the churn stands out.**

Attackers change what's cheap for them: hashes, IPs, domains (Pyramid of Pain, they say). So my tools go after what they can't cheaply change.

### Track what the attacker can't change

| Tool | What it does for you on Monday |
|---|---|
| [**b64_grep**](https://github.com/twpZero/b64_grep) | Search base64-encoded logs without decoding them. One regex, straight into grep, Splunk or KQL. PowerShell `-EncodedCommand` included. |
| [**EVi**](https://github.com/twpZero/EVi) | See whether a binary is packed or encrypted in one second, as an image. |
